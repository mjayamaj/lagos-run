# Danfo Radio Audio Assets

Drop your licensed or user-supplied Afrobeats mp3/ogg files here:
- `jaga_jaga.mp3`
- `e_dey_pain_me.mp3`
- `lagos_sunset.mp3`
- `third_mainland.mp3`

Each track is referenced in `/public/songs.json` with title, artist, file path, BPM, and drop beat.
If a file is missing or not supplied, the game's built-in procedural Web Audio Afrobeats synthesizer automatically takes over with rhythmic log-drums, shakers, woodblocks, and basslines so the game is always fun and never silent!
